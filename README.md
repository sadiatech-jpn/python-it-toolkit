# Sadia's IT Toolkit 🖥️

A beginner-friendly Python command-line toolkit I built while learning Python, IT support, and networking fundamentals.

The project combines some of the concepts I'm currently studying into simple interactive tools that can be used directly from the terminal.

## Features

### 🔌 Port Lookup
Look up common network ports and see the service and purpose associated with them.

Examples include:
- 21 — FTP
- 22 — SSH
- 25 — SMTP
- 53 — DNS
- 80 — HTTP
- 110 — POP3
- 143 — IMAP
- 443 — HTTPS

### 🌐 DNS Record Helper
Learn what common DNS records are used for:
- A
- AAAA
- CNAME
- MX

### 💾 Bits & Bytes Converter
Convert between:
- Bits and Bytes
- KB and MB
- MB and GB
- GB and MB

### 🔧 Troubleshooting Helper
Provides basic troubleshooting checklists for common IT problems such as:
- No internet connection
- Slow computer
- No display
- Wi-Fi network not showing

### 📡 Networking Quick Reference
Quick explanations of:
- LAN vs WAN
- TCP vs UDP
- IPv4 vs IPv6
- DNS vs DHCP
- Wi-Fi standards
